# Vaibhav Singh Portfolio

AI Automation & Business Systems portfolio.

## Purpose
Professional portfolio for recruiters and hiring managers. Showcases work in AI automation, workflow design, API testing, UAT, and digital analytics.

## Tech Stack
- React 19 + TypeScript
- Vite 6
- Tailwind CSS v4

## Local Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
npm run preview
```

## Deployment
Deployed automatically to GitHub Pages via GitHub Actions on every push to `main`.

Live site: https://vaibhavsingh287.github.io/Vaibhav_Singh_Portfolio/
